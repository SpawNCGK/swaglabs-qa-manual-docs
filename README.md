# Desafio de Projeto: O Dia a Dia de um QA — Testes Manuais Funcionais 🧪

Este repositório foi desenvolvido para consolidar a entrega do desafio de projeto sobre a rotina prática de um **Analista de Quality Assurance (QA)**, integrado à plataforma **Digital Innovation One (DIO)**. O foco principal deste trabalho está no mapeamento estruturado de processos ágeis, engenharia de requisitos e especificação de cenários de testes manuais.

## 🎯 Contexto do Projeto
O escopo das validações toma como base o fluxo real de uso do e-commerce fictício **SwagLabs Shopping**. Através da documentação disponibilizada, foi traçado o caminho desde o levantamento técnico de histórias de usuário até a triagem e ciclo de vida de defeitos de software (bugs).

## 📁 Artefatos Inclusos na Entrega (Documento PDF)
A documentação principal foi compilada em um documento PDF consolidado contendo os seguintes pilares fundamentais exigidos pelo mercado de tecnologia:

1. **Plano de Fluxo de Trabalho (Esteira Ágil):** Mapeamento das etapas de desenvolvimento de cards dentro do Jira (`Backlog`, `To Do`, `In Progress`, `Code Review`, `In Test / QA`, `Done`).
2. **Ciclo de Vida do Bug (Defeito):** Definição operacional das transições de estados de uma falha (`Novo/Aberto` ➡️ `Em Análise` ➡️ `Em Correção` ➡️ `Pronto para Reteste` ➡️ `Fechado` ou `Reaberto`).
3. **Histórias de Usuário (User Stories):** Duas especificações completas de requisitos focadas em fluxos críticos da loja:
   * *User Story 1:* Autenticação Secura de Usuários (Login)
   * *User Story 2:* Gerenciamento Dinâmico do Carrinho de Compras
4. **Casos de Teste Estruturados (Roteiros):**
   * **2 Casos Step-by-Step (Passo a Passo):** Roteiros detalhando pré-condições, ações do testador e resultados esperados.
   * **2 Casos em BDD (Gherkin):** Escrita baseada na sintaxe comercial `Dado / Quando / Então` cobrindo cenários críticos.
5. **Arquitetura Visual de Requisitos (Mind-Map):** Estrutura em árvore para cobertura mental completa de caminhos felizes e exceções.

## 🚀 Tecnologias e Conceitos Praticados
* **Metodologia Ágil:** Scrum & Kanban no Gerenciamento de Projetos.
* **Ferramentas de Engenharia de QA:** Jira Software, Confluence e Zephyr Scale.
* **Técnicas de Modelagem de Testes:** Caixa-preta, Testes Funcionais em Nível de Sistema e Testes de Aceite de Usuário (UAT).
* **Sintaxe Ágil:** Linguagem Gherkin para especificações executáveis (BDD).
